## 1. 제 §2 지시가 또 틀렸습니다 ★

전 지시서에서 이렇게 썼습니다.

```
시설 근처에 마땅한 스팟이 없으면 1곳만 남기거나 시설 단독도 괜찮습니다.
종일 시설은 그것만으로 하루가 찹니다.
```

**독자 입장에선 맞는 말인데, 배분 알고리즘에 넣을 문장이 아니었습니다.**

| | 후쿠오카 d3 | 오사카 d3 |
|---|---|---|
| PR #235 | 25.06 / 2.12 / 11.50 km (10·5·3곳) | 4.31 / 6.46 / 4.56 km (6·3·9곳) |
| **PR #236** | **11.67 / 14.1 / 0 km (15·2·1곳)** | **4.31 / 0 / 5.17 km (6·1·11곳)** |

```
후쿠오카 day3 (1곳): 마린월드 우미노나카미치
오사카   day2 (1곳): 유니버설 스튜디오 재팬
```

5km 문턱이 **동반 스팟을 전부 쫓아냈고**, 쫓겨난 스팟은 전부 한 날로 몰렸습니다.
후쿠오카 day1이 **15곳**입니다 — 텐진·하카타·시사이드가 한 하루에 들어가 있습니다.

`마린월드`는 우미노나카미치 반도 끝이라 5km 안에 아무것도 없습니다.
**문턱이 "가까운 걸 고른다"가 아니라 "전부 버린다"로 작동합니다.**

### 세션 판단은 맞았습니다

지시서의 "비율 최소화"를 그대로 안 쓰고 **최댓값 최소화**로 바꾼 것,
**"2곳 이하로 줄이지 않는다"** 안전장치를 추가한 것 — 둘 다 옳은 판단이었습니다.

다만 그 안전장치는 재균형에만 걸려 있고, **캡이 만든 1곳짜리 날은 막지 못했습니다.**
캡이 먼저 1곳으로 만들어놓으면 재균형은 그걸 되돌리지 않습니다.

## 2. ★★★ 문제의 뿌리 — 비율을 목표로 삼은 것

234 → 235 → 236, **세 번 연속 지표를 고치자 다른 게 깨졌습니다.**

```
234  편차 2.33배   day1 9곳  6.58km
235  편차 11.82배  day1 10곳 25.06km   ← 비율 개선하려다 이상치 이동
236  편차 1410배   day1 15곳 11.67km   ← 시설 격리하려다 붕괴
```

**`최장 ÷ 최단 ≤ 1.5`라는 기준 자체가 잘못됐습니다.** 제가 만든 기준입니다.

종일시설 날짜는 이동거리 0km가 **정상**입니다. USJ에서 하루 종일 노는 게 맞습니다.
그걸 분모에 넣으면 어떤 배분도 통과할 수 없고, 통과시키려면 코스를 망가뜨려야 합니다.

### 증거 — 시설이 없으면 지금도 잘 됩니다

```
오사카 days=2 : 편차 1.19배   day1 4곳 3.99km / day2 8곳 4.73km
```

USJ가 빠진 2일 코스는 **아무 문제 없습니다.** 클러스터링도 동선도 좋습니다.
망가지는 건 오직 종일시설이 낀 경우입니다.

## 3. ★★★ 목표를 버리고 제약으로 바꾸세요

비율을 최적화하지 말고, **아래를 만족시키기만** 하세요.

| 제약 | 값 |
|---|---|
| 하루 스팟 수 | **3 ~ 8곳** |
| 종일시설 있는 날 | **2 ~ 3곳** (시설 + 1~2곳) |
| 하루 이동거리 | **40km 이하** |
| 편차 계산 | **종일시설 날짜는 제외하고 나머지끼리만** |

**편차 기준은 종일시설이 없는 날들 사이에서만 1.5배 이하**로 보세요.
시설 날짜는 애초에 비교 대상이 아닙니다.

### 캡의 5km 문턱 — 버리지 말고 "가장 가까운 것"으로

```
현재:  시설에서 5km 넘으면 전부 제외  →  시설 단독
수정:  시설에서 가까운 순으로 1~2곳을 남긴다 (거리 무관)
       단, 남긴 스팟이 시설에서 15km를 넘으면 1곳만
```

**"조건에 맞는 게 없으면 버린다"가 아니라 "제일 나은 걸 고른다"입니다.**
마린월드 옆에 아무것도 없어도, 후쿠오카 시내에서 제일 가까운 2곳을 붙이는 게
1곳짜리 날을 만드는 것보다 낫습니다.

### 쫓겨난 스팟은 한 날에 몰지 마세요

지금 후쿠오카 day1이 15곳인 이유입니다.

```
캡에서 빠진 스팟  →  각자 자기와 가장 가까운 클러스터로
                  →  받는 날이 8곳을 넘으면 다음으로 가까운 날로
```
