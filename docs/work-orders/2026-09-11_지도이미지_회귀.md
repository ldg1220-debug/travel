## 1. 해외 경로가 살아났습니다 ★

동근님이 GCP에서 `사용자인증정보` 키의 API 제한에 Directions API를 추가하셨고,
**전파에 20분 남짓 걸린 뒤 정상 작동합니다.**

```
/api/routes  해외(오사카) 구간
  1.5km → 2,390m / 33분
  3km   → 4,008m / 56분
  5km   → 7,992m / 23분
  15km  → 21,036m / 34분        ← path 좌표 60점
```

`course-brief`도 바뀌었습니다.

```
오사카 d3    API 13.5km  직선 11.42km  → 1.18배
후쿠오카 d3  API 24.5km  직선 17.76km  → 1.38배
```

**코드는 처음부터 맞았습니다.** `GOOGLE_MAPS_SERVER_KEY`를 읽는 것도,
REQUEST_DENIED를 "판단 보류"로 처리한 것도 설계대로였고,
막고 있던 건 GCP 키 제한 하나뿐이었습니다.

## 2. ★★★ 그런데 지도 이미지가 전부 null이 됐습니다

```
오사카 d3    imageUrl = null
후쿠오카 d3  imageUrl = null
경주  d1     imageUrl = null      ← 국내도
```

**어제까지 경주는 지도가 나왔습니다**(`/api/blob/course-maps/domestic/경주/1/v7.png` 실물 확인).
경로 조회가 붙으면서 **국내까지 같이 깨졌습니다.**

### 원인 추정 — Static Maps URL 길이 초과

`#242`에서 `path=`를 구간마다 하나씩 추가하도록 바꿨습니다.

```js
for (const path of mapPaths) url.searchParams.append("path", path);
```

카카오 경로는 `mapPathParam()`이 **좌표를 문자열로 나열**합니다.

```
color:0x0000ffcc|weight:3|35.83399,129.20900|35.83370,129.20897|…
```

`simplifyPath`가 구간당 60점으로 줄여도, **하루 6구간 × 60점 = 360점**,
3일이면 1,000점이 넘습니다. 좌표 하나가 20자 안팎이니 URL이 2만 자를 넘깁니다.
**Static Maps는 8,192자 상한**이라 요청 자체가 실패합니다.

구글 구간은 `enc:` 인코딩이라 짧은데, **카카오 구간이 원시 좌표라 길어집니다.**
그래서 국내가 먼저 터진 것으로 보입니다.

### 수정

```
1. 카카오 경로도 폴리라인 인코딩해서 enc: 로 넘길 것
   (decodePolyline이 courseRoute.ts에 이미 있으니 역함수 encodePolyline만 추가)

2. 그래도 길면 MAX_MAP_PATH_POINTS 를 60 → 25 로

3. 생성된 URL 길이를 재서 8,000자를 넘으면 경로선을 빼고
   마커만이라도 남길 것 — 지도가 아예 없는 것보다 낫습니다
```

**3번이 핵심입니다.** 지금은 길이 초과 하나로 지도가 통째로 사라집니다.

## 3. ★★ 여전히 로그가 없습니다

이번 추적에 **두 시간 가까이** 걸렸습니다. 이유는 하나입니다.

```
실패해도 null 하나만 돌아오고, 왜 실패했는지 아무 데도 안 남습니다.
```

Google은 거부 이유를 `error_message`에 정확히 적어 보냅니다.
그 한 줄만 로그에 있었으면 **"REQUEST_DENIED: API not authorized"** 를 보고
10분 만에 끝났을 일입니다.

지난 지시서에서 두 번 요청드린 항목입니다. **이번엔 꼭 넣어주세요.**

```
· fetchGoogleDirectionsRoute / fetchKakaoDrivingRoute
  → 실패 시 logger.warn(상태 코드 + error_message + 구간 좌표)

· generateCourseMapImage
  → 실패 시 logger.warn(HTTP 상태 + URL 길이)     ← §2가 이것 때문에 안 보였습니다

· course-brief 응답에 distanceSource: "route" | "straight"
```

## 4. ★ 도보 구간이 `/api/routes`에서 null입니다

```
0.5km 구간 → null
```

코드상 도보(1km 미만)는 실경로 조회 대상이 아니고 **직선 추정을 쓰기로**
돼 있는데, `/api/routes`는 그 경우 값을 안 돌려줍니다.

계획 탭에서 가까운 스팟들(우메다 일대처럼)은 전부 도보권이라,
**선이 하나도 안 그려집니다.** 아까 오사카 계획에서 마커만 보이고
선이 없던 게 이것으로 보입니다.

```
fetchLegRoute 가 walk 구간에도 straightRouteMeasurement 결과를 돌려줄 것
(distanceM·durationMin 은 추정값, path 는 두 좌표 직선)
```

그리고 이전 지시서의 **점선 폴백**도 아직입니다 — `path`가 비면
클라이언트가 점선이라도 그려야 합니다.
