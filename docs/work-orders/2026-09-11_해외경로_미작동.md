## 1. #246은 국내에서 정상입니다

```
/api/routes  호출 1회 (구간별이 아니라 배치)     ✅
경주 구간    직선 6.76km → 경로 11.08km / 22분    ✅ path 좌표 다수
```

## 2. ★★★ 해외는 경로 조회가 전혀 안 되고 있습니다

```
POST /api/routes   오사카 성 → 우메다 스카이빌딩
→ { "distanceM": null, "durationMin": null, "path": null }
```

같은 호출이 국내(경주)에서는 정상입니다. **해외만 전부 null입니다.**

### 그래서 `course-brief`도 아직 직선입니다

```
경주   d1   API  4.9km   직선  3.47km   → 1.41배  ✅
오사카 d3   API 14.4km   직선 14.43km   → 1.00배  ❌
후쿠오카 d3 API 32.0km   직선 32.00km   → 1.00배  ❌
```

**#242가 해외에서는 한 번도 작동한 적이 없습니다.**
제가 그때 국내(통영·경주)만 재보고 "해결됐다"고 보고했습니다. 제 검증이 부족했습니다.

블로그에도 그대로 나갔습니다.

```
maeilg.com/248  도쿄 3박4일 — "총 이동 26.2km"   ← 직선거리
```

### 원인 — `GOOGLE_MAPS_SERVER_KEY`에 Directions API가 없습니다

세션이 #242 보고서에 이미 적어두셨던 그대로입니다.

> `GOOGLE_MAPS_SERVER_KEY`(현재 "Maps Static API만" 허용)로 Directions API도
> 호출하도록 짰지만, GCP 콘솔의 API 허용 목록에 추가해야 하는지는 확인 불가

**추가해야 합니다.** → 동근님 작업 (§5)

## 3. ★★ 진짜 버그 — 실패가 조용합니다

키가 없어서 실패하는 건 설정 문제인데, **그걸 아무도 모르게 만든 게 코드 문제**입니다.

```
경로 조회 실패  →  null 반환  →  직선으로 폴백  →  로그도 지표도 없음
```

`totalDistanceKm`가 직선인지 경로인지 **응답만 봐서는 구별할 수 없습니다.**
그래서 사흘 동안 해외 글이 계속 잘못된 수치로 발행됐습니다.

### 수정

```jsonc
// course-brief 응답에 추가
"distanceSource": "route" | "straight"
```

```
· 해외 경로 조회가 실패하면 logger.warn 으로 남길 것 (지금은 조용함)
· AutoPipeline이 이 필드를 보고 "직선거리 기준" 표기를 자동으로 붙일 수 있게
```

**`STRAIGHT_LINE_DISTANCE_MODE` 스위치를 수동으로 켜고 끄던 걸 이 필드로 대체**할 수 있습니다.
그쪽 세션에는 별도로 알리겠습니다.

## 4. ★★ 계획 지도 — 경로가 없으면 선이 아예 사라집니다

오사카 계획을 열어 마커 사이를 확대해 봤습니다.

```
마커 1·2·3·4 만 있고  선이 하나도 없음
```

#246 이전에는 **점선 직선**이라도 있었습니다. 지금은 없습니다.

지시서에 이렇게 썼습니다.

```
경로 있음  →  실선, 도로를 따라감
경로 없음  →  지금처럼 점선 직선 + 시간 표시 안 함
```

**후자가 빠졌습니다.** `path`가 null이면 아무것도 안 그립니다.
사용자 눈에는 "동선 기능이 사라진" 것으로 보입니다.

```
path === null  →  두 좌표를 잇는 점선 Polyline 을 그릴 것
```

## 5. 동근님이 하실 일 — GCP 설정 5분

```
console.cloud.google.com
 → 사용 설정된 API 및 서비스 → + API 및 서비스 사용 설정
 → "Directions API" 검색 → 사용
 → 사용자 인증 정보 → GOOGLE_MAPS_SERVER_KEY 선택
 → API 제한사항 → "Directions API" 체크 추가 → 저장
```

**Places API·Maps Static API와 같은 프로젝트입니다.** 새 키는 필요 없습니다.

> Directions API는 무료 한도가 있고, `course_cache`에 결과가 저장돼
> 지역·일수 조합당 1회만 호출합니다.

끝나면 알려주세요. `/api/routes`로 오사카 구간을 다시 재보겠습니다.
