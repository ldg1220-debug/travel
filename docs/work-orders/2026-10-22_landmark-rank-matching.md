## 처리 결과

- ① `assignLandmarkRanks`(순수 함수로 분리): 장소 id 일치가 먼저, 그 밖엔 이름 **전체**(정규화) 일치 + 300m 이내만. 음식점·술집·카페·숙소·스파(`meal`·`isLodging`·`isSpa`·`courseSpotCategory`)에는 달지 않는다. 규카츠 집이 "도톤보리"를 이름에 포함해 L1을 받던 경로가 사라진다.
- ② 풀 항목 하나는 최대 1 스팟(id 일치 → 이름 일치 순으로 처리하며 사용한 항목은 제외).
- ③ 원인 추정: 직선 ≤2km 인 대중교통 비상식 구간은 transit-sanity 가 **도보**로 바꾸는데, 실제 도보 경로(피크의 가파른 길)가 43분이어도 그대로 두었다. 실제 도보가 30분을 넘으면 차량으로 바꾸도록 고쳤다(`TRANSIT_SANITY_WALK_MAX_MIN`). 지시서는 "보고만"이라 적었으나 확인 항목에 기대값이 있어 작은 수정으로 넣었다. 로그 `[courseBrief] transit-sanity … → mode=car` 로 확인한다. 실제 로그는 못 봐 추정이다.
- 버전은 올리지 않았다(저장된 브리프는 다음 재생성 때 반영).
