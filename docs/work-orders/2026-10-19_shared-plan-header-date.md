- 공용 규칙 `src/lib/planDay.ts`(`planDayNumber` · `formatPlanDay` · `planHeaderDateLabel`): 날짜 미정으로 담은 내 계획(항목 `dayNumber`) 또는 보고 있는 콘텐츠 공유 일정(스토어 `viewerContentPlan`)이면 날짜 대신 "N일차", 아니면 기존 날짜 표기.
- §2① AppBar 헤더: 콘텐츠 공유 일정은 "2박3일 코스 · 공유됨", 날짜 미정 내 계획은 "N일차".

- §2③ PlannerBoard 토스트·되돌리기 토스트·예산 팝업, ScheduleModal 일정 요약이 모두 `formatPlanDay` 를 사용.
