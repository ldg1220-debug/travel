## 0-1. 배경

블로그 → 트레쥴 코스 → 일정 저장은 블로그 유입이 앱 사용자가 되는 핵심 경로입니다. 그런데 저장된 일정에서는 장소가 **이름·시간 블록**으로만 보입니다.

## 1. 증상

```
① 일정 카드(하노이 오페라 하우스 · 메종 센 뷔페 …) 를 누르면 "일정 수정" 모달(날짜·시간·예산)만 뜸
   → 사진 · 평점 · 리뷰 수 · 주소 · 영업 여부 · Google Maps 링크 등 장소 정보가 없음
   (앱에서 장소 검색으로 담은 장소는 이런 정보가 보임 — 같은 수준이어야 함)
② 공유 계획 화면("여행자님의 계획이에요") 지도가 하노이가 아니라 **후쿠오카** 를 보여 줌, 일정 핀도 안 보임
   → 저장된 항목에 좌표/placeId 가 빠졌거나, 지도가 일정 범위로 맞춰지지 않음 (기본 중심값?)
③ 시작 시각이 10:17 · 11:13 · 12:36 처럼 이동시간을 그대로 더한 분 단위 — 사람이 짜는 일정처럼 5분(또는 10분) 단위 반올림
```

## 2. 할 것

```
① 코스 → 일정 저장 시 각 스팟에 placeId · lat/lng · category · (가능하면) googleMapsUri 를 담음
   (course-brief spots 에 placeId 가 없으면 brief 에 추가 — placeId 는 약관상 무기한 보관 가능)
   평점·사진·리뷰 수는 저장하지 않음 (약관) → 열 때 런타임 조회
② 일정 카드 클릭 → 장소 상세 시트를 먼저 (검색으로 담은 장소와 같은 컴포넌트)
   사진 · ★평점(리뷰 수) · 주소 · 영업 여부 · Google Maps 열기 · "평점·리뷰 정보 제공: Google Maps"
   그 아래(또는 탭)에 기존 "일정 수정"(날짜·시간·예산·삭제)
   상세 조회는 /api/places/details (mapsBudget details-enterprise 가드 안) — 한도 시 이름·주소·지도만
③ 공유 계획/내 계획 지도: 열 때 일정 항목 좌표로 fitBounds (첫 날 기준 또는 전체) · 핀 표시
   좌표 없는 항목만 있으면 지역(region) 좌표로 중심 — 다른 도시 기본값 금지
④ 시작 시각 5분 단위 반올림 (이동시간 합산 후 올림)
⑤ 이미 저장된 일정(placeId 없는 항목)은 이름+지역으로 resolvePlaceId(IDs Only, 무료) 1회 → placeId 채움
```
