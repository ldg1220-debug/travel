## 0-1. 배경

블로그 → 코스 → course-open 으로 열리는 공유 일정은 첫날이 **일정을 만든 날**입니다(예: 하노이 3일 `795bcb83…` = 10/18 시작, 10/19 에 열면 이미 지난 날짜). 사용자가 담아가면 그 지난 날짜가 그대로 내 계획이 될 수 있습니다.

## 1. 할 것

```
① "내 계획으로 담아가기" 누르면 시트(또는 모달) 한 단계:
   제목  "언제 떠나세요?"
   달력  기본 선택 = 다음 토요일 (오늘이 금·토면 그다음 주 토요일) · 과거 날짜 선택 불가
   요약  "10/24 (토) ~ 10/26 (월) · 2박3일"  (일수는 공유 일정 그대로)
   버튼  [이 날짜로 담기]  ·  보조 링크 "날짜 미정으로 담기" (날짜 없이 1일차·2일차… 로 저장, 나중에 지정)
② 담을 때 모든 항목 날짜를 선택한 시작일 기준으로 이동 (일차·시각·순서 유지)
③ 공유 일정 보기 화면 상단 날짜 표시: 과거 날짜 대신 "2박3일 코스 · 날짜는 담을 때 정해요"
④ 로그인 필요 흐름이 있으면 날짜 선택 → 로그인 → 담기 순서에서 선택값 유지
⑤ 이벤트 기록(있다면): copy_plan { region, days, startOffsetDays, undated }
```

## 2. 배포 후 Cowork 이 확인할 것

| 항목 | 기대 |
|---|---|
| course-open 하노이 3일 → 담아가기 | 날짜 선택 시트 · 기본 다음 토요일 · 과거 선택 불가 |
| 10/24 선택 후 담기 | 내 계획 10/24~10/26 · 일차별 장소·시각 그대로 |
| 날짜 미정으로 담기 | 1일차·2일차·3일차 로 저장 |
| 공유 일정 상단 | 지난 날짜 대신 "2박3일 코스" 표기 |

## 처리 결과 (2026-10-19)

- §1① "내 계획으로 담아가기" → `TripStartDateSheet`("언제 떠나세요?", 달력 입력 min=오늘, 기본 다음 토요일(금·토면 그다음 주), 요약 "10/24 (토) ~ 10/26 (월) · 2박3일", [이 날짜로 담기] · "날짜 미정으로 담기").
- §1② `POST /api/itineraries/{token}/copy` 가 `{startDate}` / `{undated}` 를 받아 항목 날짜를 이동(일차 간격·시각·순서 유지). 지난 날짜는 400(서버 시계가 UTC라 어제까지 허용). 본문 없는 옛 호출은 오늘 기준 그대로.
- 날짜 미정: 항목에 `dayNumber`(1부터)를 넣고 날짜 필드는 정렬용 임시 값(다음 토요일부터). 화면은 "N일차"로 표시, 상단 배너 "날짜 정하기"로 같은 시트를 열어 나중에 지정(임시 표기 제거).
- §1③ 콘텐츠 공유 일정(origin='content') 보기: 컬럼 헤더를 "N일차"로, 배너 아래 "2박3일 코스 · 날짜는 담을 때 정해요".
- §1④ 비로그인이면 선택값(JSON)을 sessionStorage 에 남기고 로그인 후 이어서 담음(옛 형식 토큰 문자열도 호환).
- §1⑤ `copy_plan { region, days, startOffsetDays, undated }` 이벤트 추가.
