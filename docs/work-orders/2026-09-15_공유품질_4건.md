## 1. ★★★ 카카오톡 공유 카드에 이미지가 없습니다

공유했을 때 제목 한 줄과 "보러 가기"만 뜹니다.

실측입니다.

```
og:title        "5월22일 ~ 26일 후쿠오카 - 트레쥴"
og:description  "해외 여행 일정 · 트레쥴에서 함께 계획한 여행을 확인하세요."
og:image        ★ 없음
og:type         ★ 없음
```

**`og:image`가 없어서 썸네일이 안 뜹니다.**

### 이미 만들 수 있습니다

`course-brief`용 정적 지도 생성기(`generateCourseMapImage`)가 이미 동작합니다.
번호 마커 + 실제 도로 경로가 그려진 이미지가 나옵니다.

```
GET /api/og/plan/{shareToken}.png
  → 저장된 계획의 좌표로 같은 방식의 지도 생성 (Blob 캐시)

<meta property="og:image" content="…/api/og/plan/{shareToken}.png">
<meta property="og:type" content="article">
```

### 설명도 바꾸세요

```
지금:  "해외 여행 일정 · 트레쥴에서 함께 계획한 여행을 확인하세요."
변경:  "4박 5일 · 19곳 · 캐널시티 하카타, 다자이후 텐만구 외"
```

**일반 문구는 정보가 0입니다.** 카톡에서 이 한 줄이 클릭을 결정합니다.

> 카카오톡은 OG를 캐시합니다. 바꾼 뒤에도 옛 카드가 보이면
> [카카오 디버거](https://developers.kakao.com/tool/clear/og)에서 초기화하세요.

## 2. ★★ 공유 이미지가 하루치만 나옵니다

`이미지로 저장 → 스토리 9:16` 결과가 **Day 1/4** 만 담고 있습니다.
4박 5일 계획인데 첫날 4곳만 보입니다. 아래 2/3은 빈 여백입니다.

**"컨셉이냐"고 물으셨는데, 그렇게 보기 어렵습니다.**
여백이 의도된 디자인이라면 날짜 선택 UI가 있어야 하는데 없습니다.

### 수정

```
9:16 (스토리)   전체 일정을 담되, 날짜별 섹션으로 이어서
1:1 (정사각)    하루치 — 지금 형태가 맞음
```

장소가 많으면 한 장에 안 들어갑니다.

```
· 20곳 이하  →  한 장에 전부
· 20곳 초과  →  "1/2", "2/2" 로 나눠 2장 생성
```

**빈 여백을 남기느니 지도를 넣으세요.** 상단 1/3에 경로 지도, 하단에 목록이면
스토리 비율이 자연스럽게 채워집니다.

## 3. ★★ 동선이 검정 실선이라 구분이 안 됩니다

계획 지도에서 경로가 **전부 같은 검정 선**입니다.
스크린샷을 보면 1→2→3→4가 서로 겹쳐 지나가는데 어느 게 어느 구간인지 안 보입니다.

동근님 제안(핀 색상 + 화살표)이 맞습니다. 구체적으로는:

```
· 구간마다 다른 색  — 1→2 파랑, 2→3 초록, 3→4 주황 …
  (핀 색상과 같은 계열로 맞추면 눈이 따라갑니다)
· 진행 방향 화살표  — 선 중간에 ▶ 마커
· 선 굵기 3~4px, 불투명도 0.8
```

Google Maps JS의 `Polyline`은 `icons`로 화살표를 넣을 수 있습니다.

```js
icons: [{ icon: { path: google.maps.SymbolPath.FORWARD_CLOSED_ARROW },
          offset: '50%', repeat: '120px' }]
```

**날짜가 다르면 색 계열도 다르게** 해주세요. 3일 계획이면 하루씩 구분돼야 합니다.

> `course-brief` 정적 지도는 파랑 단색(`0x0000ffcc`)입니다.
> 거기도 같이 바꾸면 블로그 이미지까지 좋아집니다. 다만 **URL 길이 상한**이
> 있으니 색을 나누면 `path=` 개수가 늘어납니다 — 8,000자 방어 로직 확인하세요.

## 4. 참고 — "로그인되어 있는데?"

제가 비로그인 화면을 확인한 건 **앱 내장 브라우저**입니다.
동근님 Chrome과는 별개 프로필이라 트레쥴 세션이 없습니다.

```
Chrome (동근님, 로그인)      →  배너·담아가기 없음   ← 본인 계획이라 정상
내장 브라우저 (세션 없음)      →  "당근당근님의 계획이에요" + 담아가기 ✅
```

**동작은 설계대로입니다.** 본인 계획에서 "담아가기"가 뜨면 오히려 이상합니다.

다만 확인 못 한 경우가 하나 남았습니다.

```
로그인은 했지만 남의 계획을 여는 경우  →  배너·담아가기가 떠야 함
```

**다른 계정이 없어서 이건 확인 못 했습니다.** 테스트 계정 하나 만드시면
제가 확인하겠습니다. 이 경로가 실제 사용 패턴(친구가 공유받아 로그인 후 담기)에
가장 가깝습니다.
