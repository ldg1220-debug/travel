## 1. 증상 — 재현했습니다

`/planner` 지도에서 장소를 클릭하면 이 말풍선이 뜹니다.

```
Tempozan Ferris Wheel

34.65630, 135.43096

[관심 장소에 저장]
```

**이름과 위경도, 저장 버튼이 전부입니다.**
평점·리뷰수·카테고리·주소·사진이 하나도 없습니다.

이름도 **영문 그대로**입니다.

---

## 2. ★★★ 원인 — 서버는 이미 전부 갖고 있습니다

같은 장소를 앱의 검색 API로 조회하면 이렇게 나옵니다.

```
GET /api/places/search?q=Tempozan Ferris Wheel
{
  "placeId": "ChIJQ-VhVYvoAGARJsKgJKTie_4",
  "name": "덴포잔 대관람차",          ← 한글 이름이 있습니다
  "nativeName": "Tempozan Ferris Wheel",
  "category": "ferris_wheel",
  "color": "#FF6B6B",
  "lat": 34.65626, "lng": ...,
  "rating": ..., "reviewCount": ..., "address": ...
}
```

해유관도 마찬가지입니다.

```
GET /api/places/search?q=해유관
  name "해유관" · nativeName "Osaka Aquarium Kaiyukan"
  category "aquarium" · rating 4.5 · reviewCount 61,228 · address "1-…"
```

사진도 별도 엔드포인트가 살아 있습니다.

```
GET /api/places/details?placeId=…   → photoNames[…]
```

**데이터가 없는 게 아니라, 말풍선이 그 데이터를 안 부르고 있습니다.**

### 추정 — 구글 지도 기본 POI 클릭 이벤트만 쓰고 있습니다

구글 지도 JS API에서 지도에 원래 찍혀 있는 POI를 클릭하면
클릭 이벤트로 **이름·좌표·`placeId`** 가 옵니다.

지금은 그중 **이름과 좌표만 그대로 표시**하는 것으로 보입니다.
그래서 영문 이름이 나오고 평점이 없습니다.

**`placeId`는 이미 손에 들어옵니다.** 그걸로 조회만 하면 됩니다.

---

## 3. 수정

```
지도 POI 클릭
  → event.placeId 획득
  → /api/places/search (placeId 조회 지원 추가) 또는 /api/places/details 호출
  → 말풍선을 탐색 탭 카드와 같은 내용으로 렌더
```

> `/api/places/search?placeId=…` 는 지금 `{"places":[],"source":"mock"}` 를 반환합니다.
> **`q`만 지원하고 `placeId`는 안 받는 것으로 보입니다.** 여기에 `placeId` 분기를 더하거나,
> `/api/places/details`를 쓰세요.

### 말풍선에 넣을 것

```
[사진]  덴포잔 대관람차                    ★4.6 (리뷰 12,345)
        관람차 · 오사카시 미나토구 …
        [일정에 추가]  [관심 장소에 저장]
```

| 항목 | 지금 | 변경 |
|---|---|---|
| 이름 | 영문 | **한글 `name`** (없으면 `nativeName`) |
| 평점·리뷰수 | 없음 | 표시 |
| 카테고리 | 없음 | 표시 |
| 주소 | 좌표 | **주소로 대체** |
| 사진 | 없음 | 1장 |
| 버튼 | 저장만 | **일정에 추가** 추가 |

**좌표는 사용자에게 보여줄 정보가 아닙니다.** 주소로 바꾸세요.

---

## 4. ★ 검색 드롭다운도 절반만 보여줍니다

검색창에 `카이유칸`을 치면 드롭다운은 이렇게 나옵니다.

```
해유관                ★4.5
Kuma Kafe            ★4.7
Kadoya Shokudo       ★4.3
```

**평점만 있고 리뷰수·카테고리가 없습니다.** 응답에는 둘 다 들어 있습니다.

```
해유관  ★4.5 (리뷰 61,228) · 수족관
```

`★4.7` 짜리 이름 모를 카페가 `★4.5` 해유관보다 위에 보이면 판단이 어렵습니다.
**리뷰수가 있어야 그게 구분됩니다.**

그리고 결과를 고르면 지도만 이동하고 **정보 카드가 뜨지 않습니다.**
§3의 말풍선을 그대로 띄워주세요.
