## 1. ★★★ `발리`를 물으면 울산을 답합니다

AutoPipeline 쪽에서 "발리가 지원 지역인지 모르겠다"고 해서 직접 불러봤습니다.

```
GET /api/content/course-brief?region=발리&days=2
→ 200, 스팟 6곳, 3.4km, distanceSource=route, imageUrl 있음
```

**응답은 정상처럼 보입니다.** 내용을 열어보면 이렇습니다.

```
d1  발리온천        35.406, 129.293
d1  새골못          35.401, 129.292
d1  발리정원        35.399, 129.303
d2  남창옹기종기시장  35.417, 129.283   ★4.1 (285)
d2  텐퍼센트커피 온양서희스타힐스점
d2  남창갈비        35.408, 129.297   ★3.7 (241)
```

**좌표가 전부 북위 35.4 / 동경 129.29 — 울산 울주군 온양읍입니다.**
`발리`가 그 동네 지명·상호와 매칭됐습니다.

발리 여행 글을 쓰면 **울산 온천·갈빗집 코스가 "발리 코스"로 나갑니다.**
평점도 리뷰수도 진짜라 검증 단계에서 걸러지지도 않습니다.

**데이터가 없는 것보다 나쁩니다.** 없으면 스킵되는데, 이건 자신 있게 틀립니다.

## 2. 지원 지역 목록과 실제 동작이 어긋납니다

```
GET /api/content/regions
→ 국내 61곳 · 해외 137곳
   상위 지역 22개: 일본 베트남 태국 대만 중국 영국 프랑스 이탈리아 스페인 독일
                  이집트 모로코 남아공 케냐 미국 캐나다 멕시코 브라질
                  아르헨티나 페루 호주 뉴질랜드
```

**인도네시아·싱가포르·홍콩·필리핀·괌이 없습니다.**
그런데 `course-brief`는 **아무 문자열이나 받아서 뭐라도 돌려줍니다.**

같이 확인한 결과입니다.

|---|---|---|
| 발리 | 6곳 · 울산 온양읍 | ❌ 완전 오매칭 |
| 싱가포르 | **2곳** · 0km | ⚠️ C-2 계약(3곳) 미달 |
| 홍콩 | 7곳 · **66.5km** (2일) | ⚠️ 확인 필요 |

## 3. ★★★ 수정 — 모르면 모른다고 하세요

```
course-brief 가 region 을 받으면:

1. regions 트리에 있는 이름인가?  →  있으면 그대로 진행
2. 없으면 → 좌표를 해석한 뒤 국가를 확인
   · 사용자가 해외를 의도했는데 결과가 국내 좌표면  →  거부
   · 국가 판정이 안 되면                            →  거부
3. 거부 응답은 명시적으로
```

```jsonc
// 404 또는 422
{ "error": "unsupported_region", "region": "발리",
  "message": "지원하지 않는 지역입니다." }
```

**`{"spots": []}` 로 조용히 비우지 마세요.** AutoPipeline이 "데이터 부족"과
"지원 안 함"을 구분해야 합니다 — 전자는 재시도할 만하지만 후자는 영영 안 됩니다.

### 최소한 이것만이라도

전체 국가 판정이 부담되면, **결과 좌표가 요청 지역의 기대 권역 밖이면 거부**하는
것만으로도 발리 사례는 막힙니다.

```
해외로 분류된 요청인데 결과 좌표가 한반도(33~39N, 124~132E) 안이면 → 거부
```

## 4. ★ 스팟 3곳 미만이면 그것도 알려주세요

싱가포르가 2곳입니다. 지금은 그냥 2곳짜리 응답이 갑니다.

```
spots.length < 3  →  { "error": "insufficient_spots", "count": 2 }
```

C-2 계약이 "3곳 미만이면 글을 쓰지 않는다"인데, **판단을 AutoPipeline에만
맡기지 말고 서버가 명시**하는 편이 안전합니다.

---

## 5. ★ 곁가지 — AutoPipeline이 지역 목록 API를 안 쓰고 있습니다

`/api/content/regions`는 PR #227에서 **소재 고갈을 막으려고** 만든 것입니다.
그런데 AutoPipeline은 여전히 **하드코딩 35개**를 씁니다(국내 19 · 해외 16).

```
regions API   국내 61 · 해외 137  =  198곳
AutoPipeline  국내 19 · 해외 16   =   35곳
```

게다가 하드코딩 목록에 **싱가포르·홍콩·세부·괌**이 들어 있는데
regions 트리에는 없는 지역들입니다. 목록이 서로 어긋나 있습니다.

이건 AutoPipeline 쪽 작업이라 별도로 전달하겠습니다. 여기서는
**§3의 거부 응답이 있어야 그쪽에서 안전하게 목록을 넓힐 수 있다**는 점만 짚어둡니다.
