## 3. ★★★ 오늘 바로 되는 것 — 후기 페이지를 sitemap 에 넣으세요

`/trip/5`는 **이미 SSR 이 완벽합니다.** 제목도 본문도 HTML 에 들어 있습니다.
**색인만 안 되고 있습니다.**

```
sitemap 에 공개(전체공개) 후기 전부 추가
  · 비공개 / 메이트공개 / 특정인공개 는 제외
  · lastmod = updatedAt
```

**코드 한 덩어리로 끝나고, 지금 있는 콘텐츠가 즉시 검색 대상이 됩니다.**
후기가 늘어날 때 자동으로 들어가게 하세요.

## 4. ★★★ 본체 — 코스 페이지에 주소를 주세요

```
/course/{지역}/{일수}        예)  /course/경주/2박3일
```

### 서버에서 렌더해야 합니다

```
❌  클라이언트에서 course-brief 를 불러 그리기   →  봇이 빈 페이지를 봄
✅  서버에서 course-brief 를 불러 HTML 에 담기
```

`/discover`가 지금 전자입니다. 그래서 지역명이 0개입니다.

### 페이지에 들어갈 것

```
h1        경주 2박3일 코스
요약      총 이동 24.3km · 8곳 · 2일
일자별    표 — 순서 / 장소 / 다음까지 이동 / 평점(리뷰수)
지도      course-brief 의 imageUrl
설명      각 장소 2~3문장 (리뷰 근거)
CTA       "내 계획으로 담아가기"  →  로그인 →  담기
```

```
metadata
  title        경주 2박3일 코스 — 8곳, 총 24.3km
  description  실제 평점과 이동시간으로 짠 경주 2박3일 동선
  og:image     course-brief 의 imageUrl
  JSON-LD      ItemList (장소 순서) + TouristTrip
```

**후기 페이지와 상호 링크**하세요. 같은 지역 후기가 있으면 코스 페이지에서 걸고,
후기에서도 코스 페이지로 겁니다. 내부 링크가 색인을 끌어옵니다.

## 5. ★★★ 한꺼번에 594개를 내지 마세요

```
198 지역 × 3 일수 = 594 페이지
```

**한 번에 올리면 "자동 생성 대량 페이지"로 분류됩니다.**
maeilg.com 의 **미색인 216 > 색인 170** 이 바로 그 신호입니다. 같은 실수를 반복하면 안 됩니다.

```
1단계   국내 상위 20개 지역 × 2박3일        =  20 페이지
        → 2주 관찰. 색인률 · 노출 확인
2단계   색인이 붙으면 일수 확장 (1일 / 1박2일 / 3박4일)
3단계   해외로 확장
```

### 각 페이지가 서로 달라야 합니다

```
· 장소 목록이 실제로 다름          ← course-brief 가 보장
· 평점·리뷰수·이동시간이 실제 값    ← 그대로 노출
· 지도 이미지가 다름               ← 이미 생성됨
· 설명문이 템플릿 문장이 아님       ← 여기가 위험
```

**설명문을 `{지역} 여행을 계획 중이라면…` 같은 틀로 찍으면 블로그와 같은 결과가 납니다.**
장소 리뷰(`/api/places/details`의 `reviews`)에서 근거를 뽑아 쓰세요.

### 데이터가 얇으면 만들지 마세요

```
스팟 5곳 미만  ·  평점 없는 곳이 절반 이상   →  그 조합은 페이지를 만들지 않음
```

**없는 페이지가 나쁜 페이지보다 낫습니다.**
