## 처리 결과 (2026-10-16)

- §3① course-open 이 기존 공유 일정(origin='content')을 먼저 조회: 신선하면 브리프 조회 없이 그대로 재사용, 오래됐으면(planSchemaVersion<2 · placeId/좌표 없음 · generatedAt 24시간 경과) **캐시된 브리프만**(`peekBrief`, 외부 호출 없음)으로 새 행을 만들어 교체(옛 행은 contentKey 만 비워 URL 유지). 캐시가 없으면 기존 일정 유지.
- 지도 원인(코드 근거): 옛 일정의 합성 id(`content-0-0`)가 모든 코스에서 같아 기기 카탈로그에 남은 다른 도시(후쿠오카) 코스의 같은 id 로 해석됨 → `catalogPlaceFor` 가 좌표가 500m 넘게 어긋나면 다른 장소로 보고 항목 좌표를 사용. 새 일정의 합성 id 는 계획별 유일(`content-{8자}-{일}-{n}`). 하드코딩 후쿠오카 기본 중심은 항목이 하나도 없는 빈 계획에만 남음.
- §3③ 복사본(origin='copy')·사용자 계획은 조회/UPDATE 조건(origin='content')에서 제외.
- §3④ 구글 리뷰에 작성자 프로필 사진·작성자 링크·원문 링크(googleMapsUri) 추가.
