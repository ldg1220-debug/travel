## 2. ★★★ 왜 안 옮겨졌나 — 자유도가 0입니다

**days=2는 완벽합니다.**

```
오사카 d2 : day1 4곳 3.99km / day2 8곳 4.73km · 날짜 간 500m 이내 0건
경주  d1 : 정상
```

`도톤보리`가 난바 그룹(day2)에 제대로 들어가 있습니다. **같은 코드인데 days=3만 실패합니다.**

이유는 산수입니다.

```
스팟 18곳
  − 종일시설 날 3곳
  = 15곳을 2일에 담아야 하는데, 상한이 8곳
  → 7 + 8 = 15   ← 딱 맞음. 빈 자리가 없음
```

`도톤보리`를 day3으로 옮기려면 day3이 9곳이 됩니다. 가드가 막습니다.
**소속 재검사는 정상 동작했고, 옮길 자리가 없었을 뿐입니다.**

### 수정 — 자리를 만드세요

| | 현재 | 변경 |
|---|---|---|
| 하루 상한 | 8곳 | **6곳** |
| days=3 총 스팟 | 18곳 | **15~16곳** |

```
3 (시설날) + 6 + 6 = 15    ← 여유 2칸
```

**하루 8곳은 애초에 무리입니다.** 블로그 글로도 길고, 실제로 하루에 8곳을 도는
여행자는 없습니다. 6곳이면 코스도 글도 현실적이 됩니다.

스팟을 줄일 때는 **평점 × 리뷰수가 낮은 것부터** 빼세요.

## 3. ★★★ 개별 스팟을 옮기지 말고, 소구역을 묶어서 배정하세요

후쿠오카에서 모모치 해변의 세 곳이 **세 날짜로 흩어졌습니다.**

```
후쿠오카 시 박물관   day1
후쿠오카 타워        day2      ← 박물관과 415m
시사이드 모모치 해변  day3      ← 타워와 147m
```

`후쿠오카 타워`는 하카타·다자이후로 이어지는 **26.08km짜리 day2**에 끼어 있습니다.
바로 옆 두 곳은 각각 다른 날입니다.

### 원인 — 날짜의 "중심"이 실제로는 아무 데도 아닙니다

day2에는 `다자이후 텐만구`(도심 15km 밖)가 있습니다.
평균 좌표를 내면 중심이 하카타와 다자이후 사이 허공에 찍히고,
**그 허공이 모모치보다 가깝다고 계산되면 타워가 끌려옵니다.**

### 수정 두 가지

**(1) 배정 단위를 스팟이 아니라 소구역으로**

```
배정 전에: 500m 이내로 이어지는 스팟들을 하나의 묶음으로 만든다
           (A–B 500m, B–C 500m 이면 A·B·C가 한 묶음)
배정할 때: 묶음은 절대 쪼개지 않는다
```

**이것만으로 날짜 간 500m 이내 쌍이 구조적으로 0이 됩니다.**
지금처럼 나중에 고치는 게 아니라, 애초에 생기지 않습니다.

**(2) 중심을 평균이 아니라 실제 스팟으로**

```
현재: 좌표 평균(centroid)
변경: 나머지 스팟들과의 거리 합이 가장 작은 실제 스팟(medoid)
```

**medoid는 이상치에 흔들리지 않습니다.** 다자이후가 있어도 중심은 하카타에 남습니다.

## 4. ★ 브랜드 키가 어순을 못 잡습니다

같은 날에 이게 둘 다 있습니다.

```
모토무라 규카츠                      (day1)
규카츠 모토무라 후쿠오카 파르코점      (day1)
```

**같은 규카츠 모토무라입니다.** 지점 표기를 떼도 `모토무라규카츠` / `규카츠모토무라`로
달라서 통과합니다.

```
지점 표기 제거 후, 2글자 이상 토큰으로 쪼개 정렬한 것을 키로 쓰세요
  모토무라 규카츠            → [규카츠, 모토무라]
  규카츠 모토무라 파르코점    → [규카츠, 모토무라]   ← 일치
```

`dedupeByBrand`에 이 정규화만 추가하면 됩니다.
