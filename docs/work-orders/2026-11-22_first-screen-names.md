## 1. 할 것
① 표시 이름(displayName) — 한글이 없는 이름은 장소 ID 기준으로 한 번만 한글 표기를 만들어 저장·재사용하고 원문 병기(`5·4광장 (五四广场)`). 캐시를 비우지 말고 표시 단계에서 적용. `COURSE_ALGO_VERSION` 올리지 않음.
② 상호명 꼬리 정리 — 이름의 ` - ` 뒤 설명 잘라내기. 원문은 originalName 에 보존.
③ 대표 장소 선정 — 홈 카드·코스 제목·meta 설명의 대표 장소는 명소/랜드마크 카테고리만. 투어업체·스파·식당·카페·상점가 조합 제외.
④ 큐레이션 카드 숫자 — 좋아요·조회가 실제 집계값이 아니면 화면에서 제거. 실제 값이면 집계 출처를 PR 본문에 적기.
⑤ DIRECTION.md — "목표" 맨 위에 우선순위 1줄, "첫 화면·계획 저장 흐름" 아래에 "첫 화면에 보이는 장소 이름" 1줄.
