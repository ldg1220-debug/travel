## 2. ★★ 남은 것 — 후기 코스 스냅샷 백필

`2026-09-14_담아가기_검토_및_백필.md` 가 **아직 전달되지 않아** 미처리 상태입니다.
지시서를 다시 옮깁니다.

```
후기 6건 전부 coursesSnapshot = null
  → /trip/{id} 에 "이 여행의 코스" 섹션이 안 뜸
  → 담아가기 버튼도 안 뜸
  → POST /api/trip-posts/{id}/copy  →  400 "담아갈 코스가 없어요"
```

대상 3건입니다.

```
post 5  "…4박 5일 후쿠오카"  →  itineraryId 7   (19곳)
post 2  "0711-13 오사카 여행" →  itineraryId 4   (10곳)
post 7  "동래에서 커피…"      →  itineraryId 11  (6곳)
```

```sql
update trip_posts p
   set "coursesSnapshot" = jsonb_build_object(
         'title', i.title, 'region', i.region, 'items', i."placesData")
  from itineraries i
 where i.id = p."itineraryId"
   and i."userId" = p."userId"
   and p."itineraryId" is not null
   and p."coursesSnapshot" is null;
```

> **지금 백필하면 제가 오늘 복구한 내용이 스냅샷으로 얼려집니다.**
> 시각·순서를 손보실 생각이면 손본 뒤에 하세요.
> `updated_at`을 건드리면 피드 정렬이 흔들리니 정렬 기준을 먼저 확인하세요.

### 함께 처리할 것

```
· 본인 후기에는 담아가기 버튼 숨김 (자기 글에 "담아가기"는 어색)
· 담아온 계획에 출처 표시 — sourceReviewId 를 저장만 하고 화면에 안 씁니다
```
