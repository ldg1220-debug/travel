## 2. ★★★ 남은 문제는 하나 — 밀려난 스팟이 엉뚱한 날에 있습니다

8곳 상한을 넘긴 스팟이 **지리적으로 맞지 않는 날**로 갑니다.

```
후쿠오카 시 박물관(day2)  ~  후쿠오카 타워(day3)  =  415m
```

**박물관과 타워는 같은 모모치 해변에 붙어 있습니다.** 그런데 박물관만 day2에 있고,
day2는 하카타·다자이후로 이어지는 **28.59km짜리 날**입니다.
박물관이 day3으로 갔으면 day2는 짧아지고 day3은 자연스러워집니다.

오사카는 더 눈에 띕니다.

```
도톤보리(day1)  ~  돈보리 강 크루즈(day3)   137m
                ~  규카츠 모토무라 난바점(day3)  239m
                ~  신사이바시스지 상점가(day3)  421m
                ~  구로몬 시장(day3)          587m
```

**도톤보리 하나가 우메다 날(day1)에 잘못 들어가서** day3의 네 스팟과 겹칩니다.
독자는 1일차에 도톤보리를 갔다가 3일차에 그 앞 강에서 크루즈를 탑니다.

### 원인 — 캡·초과분 이동 뒤에 소속을 다시 안 봅니다

```
클러스터링(소속 결정) → 캡 → 초과분 분산 → 재균형
                          ↑ 여기서 스팟이 옮겨다니는데
                            소속을 다시 계산하지 않음
```

### 수정 — 마지막에 소속 재검사 한 번

```
모든 배분이 끝난 뒤, 각 스팟에 대해:
  자기 날의 클러스터 중심보다 다른 날의 중심이 더 가까우면 → 옮긴다
  단, 양쪽 날이 모두 3~8곳(시설 날은 2~3곳)을 유지할 때만
  더 이상 옮길 게 없을 때까지 반복 (최대 5회)
```

**k-평균의 배정 단계를 한 번 더 도는 것**입니다. 새 알고리즘이 아니라,
이미 있는 걸 캡 이후에 한 번 더 적용하는 것뿐입니다.

크기 조건을 붙였으니 **3~8곳 가드를 깨지 않습니다.** 이번에 넣으신 가드를 그대로 씁니다.

## 3. ★★ 같은 체인이 3곳 들어갑니다

후쿠오카 3일 코스에 이게 다 들어 있습니다.

```
모츠나베 라쿠텐치 이마이즈미 총본점   (day1)
원조 모츠나베 라쿠텐치 텐진본점       (day1)   ← day1에만 두 곳
원조모츠나베 라쿠텐치 니시나카스점    (day2)   ← 텐진본점과 364m
```

**한 코스에 같은 모츠나베 집 세 지점입니다.** 블로그 글로 나가면 바로 티가 납니다.

현재 근접 중복 제거는 100m 무조건 / 100~300m 카테고리 일치인데,
**364m라서 통과하고, 애초에 "같은 브랜드"를 보지 않습니다.**

### 수정

```
상호명에서 지점 표기를 떼고 비교:
  "원조", "총본점", "본점", "○○점", "분점", 공백 제거
  → "모츠나베라쿠텐치" 3건이 같은 이름으로 묶임
  → 평점×리뷰수가 가장 높은 1곳만 남긴다
```

거리와 무관하게 **코스 전체에서 같은 브랜드는 1곳**입니다.
지점명 규칙은 한국·일본 상호에 공통이라 이 정도로 대부분 잡힙니다.

## 4. 손대지 않아도 되는 것

`유니버설 스튜디오 재팬` 날짜의 동반 2곳이 신사이바시라 멉니다.
**제 §6 기대가 비현실적이었습니다** — USJ 인근에 붙일 만한 스팟이 애초에 없습니다.
"거리 무관 최근접 2곳"으로 구현하신 게 맞고, 그 결과가 신사이바시인 것도 맞습니다.

§2의 소속 재검사가 들어가면 이 둘도 day3으로 정리될 가능성이 높습니다.
**그러면 USJ 날짜가 2곳(시설 + 1곳)이 되는데, 그게 정상입니다.** 그대로 두세요.

후쿠오카 day2의 28.59km는 `다자이후 텐만구`(도심 15km 밖) 때문입니다.
40km 안이고, 박물관이 day3으로 빠지면 더 짧아집니다. **별도 조치 불필요합니다.**
