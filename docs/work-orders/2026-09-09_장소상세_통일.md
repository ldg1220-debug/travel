## 2. ★★★ 문제 — 같은 장소인데 화면이 네 개입니다

`해유관` 하나를 여는 경로마다 **다른 컴포넌트**가 뜹니다.

| 경로 | 보이는 것 | 평점 | 사진 | 리뷰 |
|---|---|---|---|---|
| 탐색 → **테마파크** 카드 | 큰 사진 · 주소 · **영업 중** · 사진 4장 · 구글맵 링크 · **트레쥴 후기 + 구글 리뷰** | ✅ | ✅ | ✅ |
| 계획 → 지도 말풍선 | 사진 1 · 평점 · 카테고리 · 주소 | ✅ | 1장 | ❌ |
| 탐색 → **관광지** 카드 | 지도 썸네일 · 주소 · 카테고리 칩 · 관심 폴더 · 메모 | ❌ | ❌ | ❌ |
| 탐색 → 지도 핀 | 이름 · 주소 · 버튼 2개 | ❌ | ❌ | ❌ |

**같은 `해유관`인데 어디서 눌렀느냐에 따라 정보량이 완전히 다릅니다.**

특히 세 번째가 문제입니다. 탐색에서 **관광지** 섹션의 해유관을 누르면
**저장 다이얼로그**가 뜹니다 — 평점도 사진도 리뷰도 없이 "저장하시겠습니까"만 묻습니다.
같은 화면 안에서 **테마파크** 섹션의 해유관을 누르면 리뷰까지 다 나옵니다.

## 3. 수정 — 상세 시트 하나로 통일

**기준은 테마파크 경로에서 뜨는 상세 시트입니다.** 그게 가장 완성된 화면입니다.

```
어디서 장소를 누르든  →  같은 PlaceDetailSheet 를 연다

  대표 사진
  이름 (한글) · 주소
  ★평점 · 리뷰 N · 영업 상태
  사진 4장
  구글맵에서 메뉴판·전체 리뷰 보기
  ── 리뷰 ──
  트레쥴 후기 (있으면 우선)
  구글 리뷰
  ──────────
  [일정에 추가]  [관심 장소에 저장]
```

### 저장 다이얼로그는 없애지 말고 2단계로

지금 저장 다이얼로그에만 있는 기능이 있습니다 — **카테고리 칩·관심 장소 폴더·메모.**
이건 유용하니 버리지 마세요.

```
상세 시트에서 [관심 장소에 저장] 을 누르면
  → 그때 폴더·메모 입력이 뜬다
```

**"저장하려다 정보를 못 보는" 지금 순서를 뒤집는 것**입니다.
정보를 먼저 보고, 저장할지 정하고, 그다음 폴더를 고릅니다.

### 지도 말풍선은 지금이 맞습니다

지도 위 말풍선은 좁으니 **요약형이 맞습니다.** #243에서 만든 형태를 유지하되,
**말풍선을 눌렀을 때 같은 상세 시트가 열리게** 해주세요.

```
말풍선(요약)  →  누르면  →  상세 시트(전체)
```

탐색 탭 지도 핀 말풍선도 계획 탭과 같은 컴포넌트를 쓰게 맞춰주세요.
지금은 이름·주소만 나옵니다.

## 4. ★ 곁가지 — 해유관이 두 카테고리에 중복 노출됩니다

```
"해유관" 검색 결과
  관광지 3 · 테마파크 2 · 쇼핑몰 2 · 카페 1 · 기타 6
  → 해유관이 관광지에도, 테마파크에도 있음
```

동근님이 두 경로로 눌러보신 이유가 이것입니다.

구글 플레이스가 타입을 여러 개 주기 때문인데, **한 장소는 한 섹션에만** 넣으세요.
`liveCategoryBucket`에서 우선순위를 정해 첫 번째 버킷 하나만 쓰면 됩니다.
같은 카드가 두 번 보이면 결과가 실제보다 많아 보입니다.
