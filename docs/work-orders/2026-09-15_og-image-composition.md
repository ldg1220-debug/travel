## 3. 수정 세 가지

### ① 전체가 아니라 한 날만 그리세요

OG 이미지는 **대표 한 장**입니다. 전 일정을 담으면 축척이 무너집니다.

```
스팟이 가장 많은 날 하나를 골라 그린다
  후쿠오카 예: 2일차(8곳, 텐진~하카타) → 도심이 꽉 참
```

다일정 전체는 **9:16 스토리 이미지**가 이미 맡고 있습니다. 역할을 나누세요.

> 대안: 전체를 담되 **중앙값에서 크게 벗어난 스팟은 제외**하고 경계를 잡기.
> 다만 위 방법이 더 단순하고 결과가 예측 가능합니다.

### ② 라벨을 빼거나 날짜만 남기세요

Google Static Maps의 `label:`은 **한 글자만** 받습니다.
그래서 10번째부터 `A, B, C…`로 넘어가 **순서를 읽을 수 없습니다.**

```
지금:  1~9 그다음 A~J
변경:  라벨 없는 점 마커 + 시작점만 강조
```

썸네일 크기에서 라벨은 어차피 안 읽힙니다. **동선 모양이 보이면 충분합니다.**

### ③ 비율을 1200 × 630 으로

```
지금:  1280 × 1000  (4:3에 가까움)
권장:  1200 ×  630  (1.91:1)
```

카카오·페이스북 모두 1.91:1을 기준으로 잘라냅니다.
지금 비율이면 **위아래가 잘려나가** 의도한 구도가 깨집니다.

## 5. AutoPipeline 질문에 대한 답

그쪽 세션이 물어온 두 가지입니다.

| 질문 | 답 |
|---|---|
| `dayTotals`가 실제로 오는가 | **옵니다.** `[{day,distanceKm,spotCount}]` — 멀티데이도 정상 |
| `ratingSource`가 항상 오는가 | **항상 옵니다.** 확인한 4개 지역 전부 `"google"` |

```
경주 d1    dayTotals: d1 4.9km/4곳
오사카 d3  dayTotals: d1 15.2km/6곳, d2 17.9km/6곳, d3 0km/1곳
```

**`distanceSource`는 항상 `"route"`가 아닙니다.** 경로 조회가 실패하면 `"straight"`가
됩니다 — 그게 이 필드의 존재 이유입니다. 그쪽에서 `"straight"`일 때
"직선거리 기준" 표기를 자동으로 붙이면 됩니다.

**종일시설 날은 `distanceKm: 0`입니다.** 스팟이 1곳뿐이라 구간이 없어서인데,
지식iN 답변에서 `(총 0km)`로 나가면 이상합니다. **0이면 거리 표기를 생략**하세요.
