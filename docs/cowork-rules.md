# Cowork 작업 규칙

Cowork(작업지시서 기반 위임 작업) 전달용 규칙. 2026-09-02 사용자 전달분 — 규칙 4·5만
전달받았고 그 이전 번호(1~3)는 이 세션에 공유되지 않았다.

## 규칙 4: 작업 완료 보고 (Cowork 전달용)

작업이 끝나면 아래 형식으로만 요약한다.
CI 대기·레이트리밋 재시도·알림 확인 같은 과정 로그는 넣지 않는다.

```
## 작업 보고 — {지시서 이름}

**PR**: #번호 (병합됨 / draft / 실패)
**커밋**: sha

### 처리
| 지시서 항목 | 파일 | 무엇을 |
|---|---|---|
| §2-1 | src/... | 한 줄 |

### 지시서와 다르게 한 것 ★
- 없으면 "없음". 있으면 **무엇을·왜** 반드시 기재

### 검증한 것 / 못한 것
- 한 것: tsc/lint/test 통과, curl 실응답 확인 등
- 못한 것: 이유와 함께

### Cowork가 확인할 것
- 확인 URL 또는 명령어
- 기대값
```

## 규칙 5: PR 병합

draft 해제(ready for review)에서 실패하면 재시도하지 말고
"PR #N 준비 완료 — 브라우저에서 Ready for review → Squash and merge 필요"
라고 보고하고 종료한다.
