트레쥴 Autopilot 작업 방향성

이 파일은 동근님이 정하는 방향입니다. Autopilot 은 매 실행마다 이 파일을 먼저 읽고, 과제를 고를 때 아래 순서를 따릅니다. 방향을 바꾸려면 이 파일만 고치면 됩니다.

목표 (2026-11 기준)
사람 방문 늘리기 — 현재 사람 방문 하루 10회 미만. 검색·블로그(maeilg.com)에서 트레쥴로 들어오는 길을 넓힌다.
제휴 수익 첫 발생 — Klook(숙소 8%·입장권), eSIM(Yesim·Airalo). 아직 수익 0원.
무료 유지 — Google Maps·Places 무료 한도 안, Vercel Hobby, 추가 유료 서비스 없음.
지표 (판단 기준)
/api/health courseBuild.visitsBySource.human (사람 방문)
lodging_click · 제휴 링크 클릭 이벤트 수
Google 사용량: 각 항목 이번 달 count ≤ freeLimit 의 50%
현재 단계 과제 (위에서부터)
오류·회귀 0 — health 경고, 코스 생성 실패, 깨진 링크·제휴 파라미터 누락부터.
색인 코스 12개 페이지 품질 = 검색 유입의 입구
제목·설명(meta)·구조화 데이터(ItemList/TouristTrip)·내부 링크(같은 나라 다른 코스, 일수 변형)
페이지 속도(LCP)·이미지 크기
대표 명소 포함·하루 식사 ≥1 유지 (기존 규칙)
제휴 동선 — 코스 페이지·계획 화면에서 숙소/입장권/eSIM 링크가 자연스러운 위치에 보이는지, 클릭 이벤트가 빠짐없이 남는지. 링크는 검색 결과/목록 페이지로만(특정 호텔 추천 금지).
블로그 → 트레쥴 연결 — 블로그 CTA 가 정확한 코스 페이지로 가는지, utm 이 남는지.
첫 화면·계획 저장 흐름 — 처음 온 사람이 코스 보기 → 내 일정으로 저장까지 막힘 없는지.
진행 규칙: 점검에 이상이 없으면 매 실행 '현재 단계 과제' 중 1건을 반드시 골라 작업한다(근거가 약하면 측정·계측 추가부터).
진행 규칙(보강): 점검에 이상이 없고 열린 PR 이 없으면 아래 백로그에서 위에서부터 완료 안 된 1건을 반드시 골라 작업한다. 근거가 부족하면 측정·계측 추가부터 한다. '근거 약함'으로 건너뛰지 않는다.
