# 2026-08 리디자인 — 작업 문서 모음

이 폴더는 2026년 8월 리디자인 검토·작업지시서와 그 근거가 된 목업을 보관한다.
Claude Code 세션이 바뀌어도 맥락을 잃지 않도록, 매번 파일을 첨부하는 대신
경로만 참조하면 되게 하려는 목적이다.

## 문서

- **`디자인개선안_검토.md`** — 목업에 대한 첫 리뷰. 강점(브랜드 컬러 정박,
  홈 상태 화면화, trip-mode)과 리스크(데이터 가용성, 접근성, 매출 동선 누락)를 짚는다.
- **`작업지시서_리디자인_적용.md`** — 실제 구현 지시서. Phase 0(토큰) ~ 3(트립모드)
  로 쪼갰고, 각 Phase의 선행 조건·완료 조건·제외 항목을 명시한다. **Phase 0
  구현 기록** 섹션에 실제 반영한 색상 값과 근거가 있다.
- **`작업지시서_166_saves필터_및_구조통합.md`** — PR #166 버그 원인 분석 +
  `/discover`·`/course` 구조 통합 제안(#167의 근거 문서).

## 목업 (`mockups/`)

`window.T` 전역에 의존하는 독립 스케치 — **참조용이며 그대로 이식할 코드가 아니다.**
레이아웃·위계·컴포넌트 구성만 참고하고, 실제 구현은 기존 코드베이스 규약을 따른다.
목업에 있으나 현재 데이터/기능이 없는 항목(해외 전용 평점, 정밀 도보 이동시간,
실시간 ETA, 체크인)은 절대 임의로 채우지 않는다 — 데이터가 없으면 그 영역
자체를 렌더하지 않는다(#163의 "가짜 숫자 금지" 원칙).

- `shared/tokens.jsx` — 팔레트·아이콘·로고타입
- `shared/components.jsx` — Button/Card/Chip/PlaceCard 등 공용 컴포넌트
- `artboards/home-desktop.jsx`, `home-mobile.jsx` — Phase 1
- `artboards/search-desktop.jsx` — Phase 2
- `artboards/trip-mode.jsx` — Phase 3
- `artboards/onboarding.jsx` — Phase 1 (신규 사용자 스테퍼)
- `reference/tradule_home.png` — 현재 홈 스크린샷(비교용)
