# 파트 A — 플레이스토어 에셋

## A-0. 결론: 지금 확정하지 마세요

Phase 0(#170)에서 브랜드가 **인디고 → 오렌지**로 이미 전환됐습니다.
현재 시안 7종은 전부 **인디고 로고 + 라벤더/퍼플 장식** 기준이라 그대로는 못 씁니다.

또 대표 이미지가 **곧 교체될 홈 화면**을 보여주고 있어(아래 A-1), Phase 1까지 끝난 뒤
확정하는 것이 재작업을 막습니다.

**지금 할 것: 톤·구성 실험으로 두되, A-2의 사실관계 오류만 즉시 제거.**

## A-1. 대표 이미지가 폐기 예정 화면입니다 ★

세로 히어로 카드("여행의 모든 순간을 트래줄 하나로")가 **현재 홈 화면**을 보여줍니다.

```
여행 계획짜기 / 계획 / 여행 보관함 / 후기 피드 / 커뮤니티  ← 동일 카드 5개
```

이 화면은 리뷰에서 **"홈이 랜딩이 아니라 메뉴판"** 으로 지적됐고,
리디자인 Phase 1이 정확히 이걸 없애려고 만든 화면입니다.
게다가 "이렇게 써보세요" 온보딩 배너까지 포함돼 있어 가장 정돈이 덜 된 상태를 노출합니다.

### 레퍼런스와의 차이

| 앱 | 1번 스크린샷 |
|---|---|
| Ringuage | **"듣기는 되는데 말은 왜 안 나올까?"** — 문제 제기 |
| 지갑지켜 | **"내 돈 흐름, 쉽게 관리"** — 결과 약속 |
| Medication | **"Never miss your medication"** — 결과 약속 |
| **트래줄 (현재)** | **메뉴 5개 목록** — 기능 나열 |

플레이스토어는 첫 2~3장이 설치를 결정하고 대부분 그 이상 스크롤하지 않습니다.
1번을 메뉴 목록에 쓰는 것은 가장 비싼 슬롯의 낭비입니다.

**조치:** Phase 1 홈 V1(상태 기반 히어로 — "부산 여행 13일 남았어요 / Day 2를 마저 짜볼까요?")
적용 후 촬영.

## A-2. 앱에 없는 내용이 표시돼 있습니다 — 즉시 수정 ★★

"실시간 인기 스팟" 카드에서 확인된 항목입니다.

| 시안 표기 | 실제 | 조치 |
|---|---|---|
| `첨성대 · 2.2k명 저장` | `saves`는 시드값이라 **#163에서 "N명 저장" 표기 전면 제거** | **삭제** |
| `성수동 팝업 스트리트 · 980명 저장` | 위와 동일 | **삭제** |
| `실시간 인기 스팟` / `지금 가장 많이 담긴 실시간 핫플` | 실시간 집계 아님. #163에서 **"여행자들이 많이 찾는 인기 스팟"으로 순화** | **문구 교체** |

> 스토어 이미지가 앱에 없는 기능·수치를 보여주면 리뷰 신뢰도가 떨어지고,
> 정도가 심하면 스토어 정책(오해를 부르는 스크린샷) 이슈가 됩니다.
> **다른 카드에도 `저장`·`실시간` 표기가 남아 있는지 전수 확인하세요.**

## A-3. 슬롯 배분이 제품 강점과 반대입니다

현재 7장 구성:

| 화면 | 장수 | 실제 상태 |
|---|---|---|
| 커뮤니티 | 1 | 글이 없어 카테고리를 6개 → 3개로 축소한 상태 |
| 후기 피드 | 2 (같은 화면 변형) | 작성자가 사실상 운영자 계정뿐 |
| AI 코스 | 1 | **그마저 국내/해외 선택 화면(입구)** |
| 플래너 | 1 | 양호 |
| 홈 | 1 | 폐기 예정 (A-1) |
| discover | 1 | 저장수 오류 (A-2) |

**가장 비어 있는 기능에 3슬롯, 가장 강한 기능에 1슬롯**입니다.

### AI 코스는 결과 화면을 써야 합니다

현재는 "국내 여행 / 해외 여행" 고르는 **선택 화면**입니다. 결과물이 아닙니다.
실측으로 검증된 아래 화면이 훨씬 강력합니다.

```
서울 AI 추천 동선
10:00  경복궁            서울 대표 궁궐, 역사성과 포토존 우수
11:00  영등포전통시장 순대골목
12:00  우래옥 본점        70년 역사 냉면 명가
14:00  N서울타워          야경 준비 겸 오후 전망, 필수 명소
16:00  빈브라더스 합정     한강뷰 카페, 야경 전 분위기 완성
19:00  이랜드크루즈        한강 야경 선유, 서울 최고의 야경
20:00  조용한저녁         야경 후 정취 있는 저녁식사
```

슬롯별 추천 이유가 앞뒤 맥락을 반영한다는 점이 트리플 대비 차별점이고,
프로덕션에서 정상 동작을 확인한 화면입니다.

### 권장 순서

| # | 내용 | 헤드라인 방향 |
|---|---|---|
| 1 | 문제 제기 또는 결과 약속 | "여행 계획, 3시간씩 걸리셨나요?" 또는 "지역만 고르면 하루 코스가 완성돼요" |
| 2 | **AI 코스 결과 화면** | 시간표 + 추천 이유가 보이게 |
| 3 | 플래너 지도 + 타임라인 | 현재 시안 양호 |
| 4 | 여행 보관함 (파트 B 적용 후) | "다녀온 여행이 쌓입니다" |
| 5 | discover 탐색 | A-2 수정 후 |
| 6~7 | 후기·커뮤니티 | **콘텐츠 쌓인 뒤로 미루거나 1장으로 축소** |

## A-4. 유지할 것 — 빈티지 스크랩북 톤 자체는 좋습니다

우표·워시테이프·폴라로이드·손글씨 조합은 트리플·마이리얼트립의 깔끔한 파란 계열과
확실히 구분돼 스토어 목록에서 눈에 띕니다. **방향은 유지하세요.**

다만 제작 시 두 가지:

1. **폰 목업을 더 크게.** 스토어 썸네일은 실제로 매우 작게 보이는데, 현재는 장식이 공간을
   많이 먹어 앱 화면 안 텍스트가 판독 불가입니다. 지갑지켜 시안처럼 장식은 여백으로 밀고
   폰을 키우세요.
2. **장식이 화면을 가리지 않게.** 일부 카드에서 워시테이프가 상태바를 덮고 있고,
   플래너 카드는 목업 상태바(9:41)와 앱 헤더가 겹쳐 보입니다.
3. **브랜드 색 교체.** 라벤더/퍼플 → Phase 0의 오렌지 계열. `--color-brand-*` 값 참조.

# 파트 B — 스크랩북 모티프 앱 적용 (Phase 1.5)

## B-0. 원칙: 바깥은 시끄럽게, 안은 조용하게

**스크랩북 톤을 앱 UI 전반에 적용하지 마세요.** 스탬프·테이프·손글씨가 겹치면
정보 스캔이 느려지고, 리뷰에서 지적한 대비 문제가 악화됩니다.

앱 본문은 Phase 0/1의 warm-clean 시스템을 유지하고, **아래 3곳에만** 적용합니다.
세 곳 모두 "기능적으로 스크랩북이 맞는 자리"라는 공통점이 있습니다.

---

## B-1. 여행 보관함 — 카드를 엽서/티켓 형태로 ★ 우선순위 1

`ScrapbookClient.tsx`

**왜 여기인가:** 이름부터 스크랩북이고, 다녀온 여행을 모아두는 화면입니다.
우표·티켓 모티프가 장식이 아니라 **의미**가 됩니다.

### 구현

- 여행 카드를 **엽서 또는 항공권 스텁** 형태로 (모서리 노치, 점선 절취선, 스탬프 배지)
- 완료된 여행에 **"도착 스탬프"** — 도시명 + 날짜가 찍힌 원형 스탬프
- 진행 중 / 초안은 스탬프 없이 구분
- 기존 `COVER_GRADIENTS`는 그대로 활용 (#170에서 브랜드 전환 제외한 "다양성 색" — 판단 적절함)

### 기대 효과

지금은 밋밋한 카드 리스트라 "다시 볼 이유"가 약합니다.
수집 욕구가 생기면 재방문 동기가 됩니다.

---

## B-2. 공유 이미지 — 스크랩북 카드로 렌더 ★ 우선순위 2 (바이럴 직결)

플래너의 `이미지로 저장` / `카카오톡 공유`

**왜 여기인가:** 이미 있는 기능인데 지금은 일정표를 그대로 캡처합니다.
공유 이미지는 **앱 밖으로 나가는 유일한 브랜드 접점**이고,
카카오톡으로 퍼질 때마다 노출이 발생합니다. 바이럴 계수에 직접 영향을 줍니다.

### 구현

- 공유용 렌더를 별도 레이아웃으로 분리 (화면 캡처 ≠ 공유 이미지)
- 구성: 도시명 + 날짜 + 스팟 목록(시간표) + 트래줄 로고 + 스탬프 장식
- 스토어 에셋의 빈티지 톤을 여기에 적용 — **같은 자산을 재활용**
- 세로 카드(인스타 스토리 9:16)와 정사각(피드 1:1) 두 규격 권장

### 계측 (#169 연계)

`plan_share` 이벤트에 `channel`뿐 아니라 **`format`(story/square)** 도 props에 추가하면
어느 규격이 더 공유되는지 알 수 있습니다.

---

## B-3. 빈 상태 — 손글씨 톤 + 일러스트 ★ 우선순위 3

**왜 여기인가:** 커뮤니티·보관함·discover 폴백의 빈 화면이 계속 문제였습니다
(#163 숙소 섹션 숨김, #164 커뮤니티 축소, #166 `coming_soon` 폴백).
빈 화면은 어차피 콘텐츠가 없으니 **장식이 정보를 방해하지 않습니다.**

### 적용 대상

| 화면 | 현재 문구 |
|---|---|
| 커뮤니티 | "아직 글이 없어요 / 가장 먼저 글을 남겨보세요." |
| 여행 보관함 | 저장된 여행 0건 |
| discover 폴백 | "이 조건에 맞는 장소가 아직 없어요." |
| 플래너 초기 | 빈 타임라인 |

### 구현

- 손글씨 액센트 폰트는 **빈 상태 전용**으로 제한 (본문 사용 금지)
- 간단한 라인 일러스트 (여권·티켓·지도 모티프)
- 문구는 유지하되 톤만 따뜻하게

## B-4. 하지 말 것 (명시)

- 앱 상단바·탭바·카드 리스트 등 **주요 탐색 UI에 스탬프/테이프 적용 금지**
- 손글씨 폰트를 **본문·라벨·버튼에 사용 금지** (가독성·대비)
- 스팟 카드에 장식 오버레이 추가 금지 (이미 사진·배지·평점이 있어 과밀)

## 완료 조건

**파트 A** (디자인 작업)

- 모든 카드에서 `N명 저장`·`실시간` 표기 제거 확인
- 브랜드 색을 Phase 0 오렌지 계열로 교체
- 1번 스크린샷이 Phase 1 홈 또는 결과 약속형 카피
- AI 코스는 결과 화면(시간표 + 추천 이유)
- 후기·커뮤니티 슬롯 축소

**파트 B** (Claude Code)

- 보관함 카드가 엽서/티켓 형태로 렌더, 완료 여행에 스탬프 표시
- 공유 이미지가 화면 캡처가 아닌 전용 레이아웃으로 생성, 2규격 지원
- 위 4개 빈 상태에 일러스트·손글씨 톤 적용
- 본문·탐색 UI에는 스크랩북 요소 미적용 (B-4 준수)
- 대비 회귀 없음 (Phase 0에서 잡은 AA 기준 유지)
